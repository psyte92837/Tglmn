# TGScope for Android

Локальный (local-first) сборщик и аналитика комментариев Telegram-каналов для Android.
Это нативная переработка идеи Python-проекта
[TheMyxa/telegram-parser](https://github.com/TheMyxa/telegram-parser). Код написан с нуля на Kotlin,
из оригинала заимствованы только идеи.

Ключи API, сессия Telegram, собранные данные и медиа остаются на устройстве. Наружу приложение
обращается только к Telegram API и, если вы его настроите, к LLM-endpoint.

## Возможности

| Функция | Как сделано |
|---|---|
| Выгрузка постов и комментариев | TDLib (через [tdl-coroutines](https://github.com/g000sha256/tdl-coroutines)): `getChatHistory`, `getMessageThreadHistory` |
| Инкрементальный экспорт | `lastPostId` у канала, просмотр N последних сохранённых постов (lookback), догрузка только новых комментариев |
| Атомарность | пост, его реакции, комментарии и авторы пишутся в одной транзакции Room, от старых постов к новым |
| FloodWait | собранное сохраняется, затем ожидание. В фоне длинные паузы возвращаются в WorkManager |
| Scheduler | WorkManager, периодическая задача на канал (минимум 15 минут), `SKIPPED`, если предыдущий запуск ещё идёт |
| Watch | foreground service + `openChat`: счётчики обновляются сразу, новые посты и комментарии подтягиваются пачками |
| Хранение | Room: `channel`, `post`, `comment`, `tg_user`, `reaction`, `sync_run`, `analysis` + FTS4 по комментариям |
| Просмотр | лента постов с фильтрами, дерево комментариев, профиль пользователя, полнотекстовый поиск |
| Статистика | комментарии по дням, топ авторов, топ реакций, самые обсуждаемые посты, сравнение с прошлым периодом |
| Экспорт | JSON в формате оригинала, CSV через системный диалог сохранения, опциональная анонимизация |
| LLM-анализ | любой OpenAI-совместимый endpoint (OpenAI, OpenRouter, Ollama/LM Studio в локальной сети), промпты ru/en/zh, map-reduce для длинных обсуждений |
| Безопасность | ключ БД TDLib и API-ключ LLM зашифрованы ключом из Android Keystore, бэкап отключён |

## Архитектура

```
:app             Compose UI, навигация, WorkManager (SyncWorker), WatchService
:domain          SyncEngine, WatchCoordinator, Exporter, Anonymizer, LlmAnalyzer, StatsRepository
:core:tdlib      TelegramClient: обёртка над TdlClient, машина состояний авторизации, маппинг в свои модели
:core:database   Room: сущности, DAO, агрегаты для статистики, FTS
:core:settings   DataStore + KeystoreCipher
```

### Алгоритм синхронизации

1. Читаем историю канала от новых к старым, пока не дойдём до `lastPostId` или до лимита `POST_LIMIT`.
2. Новые посты сохраняем от старых к новым. Каждый пост пишется одной транзакцией: пост,
   реакции, новые комментарии и их авторы. После коммита сдвигаем `lastPostId`.
3. Lookback: `getMessages` для N последних сохранённых постов. Обновляем счётчики и реакции,
   при росте `reply_count` догружаем новые комментарии, удалённые посты помечаем.
4. После каждых `pauseAfterPosts` постов делаем паузу `pauseSeconds`. При ошибке 429 всё
   собранное уже записано, запуск получает статус `PARTIAL`.

## Сборка

APK собирает GitHub Actions (`.github/workflows/android.yml`) при каждом пуше в `main`.
Готовые файлы лежат во вкладке **Actions → последний запуск → Artifacts**. При пуше тега `v*`
APK прикрепляются к GitHub Release.

Локально:

```bash
./gradlew assembleDebug
# app/build/outputs/apk/debug/app-arm64-v8a-debug.apk  (большинство телефонов)
# app/build/outputs/apk/debug/app-universal-debug.apk  (любая архитектура)
```

Нужны JDK 17+ и Android SDK (compileSdk 37). Нативные библиотеки TDLib приходят готовыми
в зависимости `dev.g000sha256:tdl-coroutines`, собирать TDLib не нужно.

## Первый запуск

1. Получите `api_id` и `api_hash` на <https://my.telegram.org/apps>.
2. Введите их в приложении и войдите по номеру телефона (код, затем облачный пароль, если он включён).
3. Добавьте канал по `@username` или ссылке `t.me/…`. Первая выгрузка начнётся автоматически.

## Ограничения и риски

- **Аккаунт.** Сбор идёт от пользовательского аккаунта. Telegram может ограничить аккаунты,
  которые массово читают каналы, поэтому лучше использовать отдельный аккаунт. Не отключайте
  паузы и не ставьте большие лимиты.
- **Фон на Android.** Периодические задачи не чаще раза в 15 минут. Watch держит постоянное
  уведомление, а Android 15 ограничивает такие службы примерно 6 часами в сутки. На прошивках
  Xiaomi/Huawei и подобных нужно отключить оптимизацию батареи для приложения.
- **Реакции на старые комментарии** обновляются только вместе с новыми комментариями к посту.
- **Входы через e-mail и регистрация** нового аккаунта не поддерживаются.
- **Персональные данные.** Выгрузки содержат персональные данные. Их сбор и хранение регулируются
  GDPR, 152-ФЗ и аналогичными законами, ответственность лежит на пользователе. Для передачи
  данных третьим лицам используйте анонимизацию.
- **Google Play** плохо относится к приложениям для массового сбора данных. Распространять
  лучше через APK или F-Droid.
